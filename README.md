# API testing: weather and another requests

## О портфолио

Данная коллекция создана для демонстрации навыков работы с запросами в Postman. Коллекция разделена на 2 блока: работа с реальным API (OpenWeatherMap) и работа в песочнице API (JSONPlaceholder).

## Какие навыки здесь продемонстрированы:

- **Работа с переменными:** Безопасное хранение API-ключа и базового URL;
- **Позитивные и негативные тесты:** Проверка успешных ответов с ответом 200 и обработка ошибок - 404 Not Found с проверкой текста ошибки;
- **Отправка запросов:** POST (создание), PUT (обновление) и DELETE (удаление) с передачей тела запроса (JSON);
- **Тесты:** Написание проверок на JavaScript. Тестирование статус-кодов, структуры и содержимого JSON-ответов, а также времени отклика сервера;
- **Pre-request Scripts:** Автоматическая генерация случайных данных (выбор случайного города из массива) перед отправкой запроса.
    

## Как запустить:

1. Импортируйте коллекцию (`.postman_collection.json`) и файл окружения (`.postman_environment.json`) в Postman на своём компьютере.
2. В правом верхнем углу выберите импортированное окружение **Weather Project**.
3. Откройте это окружение (иконка глаза -> Edit) и заполните пустые переменные:
   * `base_url`: `https://api.openweathermap.org/data/2.5`;
   * `api_key`: укажите ваш собственный ключ от OpenWeatherMap (если его нет, зарегистрируйтесь на [openweathermap.org](https://openweathermap.org)).
4. Сохраните изменения в окружении;
5. Нажмите правой кнопкой мыши на коллекцию, выберите **Run**, чтобы прогнать все тесты автоматически и увидеть отчёт в Collection Runner.
    

## Структура:

• **Weather** — проверка погоды (успешные и ошибочные сценарии);  
• **Various requests** — демонстрация методов изменения данных.
